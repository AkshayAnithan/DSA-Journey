# DSA Mastery

## Primary 30-Day Target

FAANG SDE-2 interview preparation through NeetCode 150. Contest-specialist techniques are deliberately secondary until core interview patterns have evidence of retention and transfer.

## Objective

Build independent problem generation: understand the prompt, derive a brute force, locate its bottleneck, exploit structure, prove the optimized approach, implement it, and transfer the idea to unfamiliar problems.

`Solved after viewing a solution` is recorded as understanding, not mastery.

## How To Use This Repository

1. Start every session with active recall from `20-Revision` before opening notes.
2. Create or update one problem record after each meaningful attempt.
3. Record the highest hint reached, the precise roadblock, and one reusable observation.
4. Revisit the problem as recall, reconstruction, and transfer according to its schedule.
5. Update confidence only from observed performance, never from familiarity.

## Non-Negotiable Solve Protocol

1. Restate the problem and identify inputs, output, and hidden assumptions.
2. Inspect constraints before naming a pattern.
3. State a brute-force method and derive its complexity from its operations.
4. Identify the exact repeated or expensive operation.
5. Form an observation and test it with an example or counterexample.
6. Request only the next necessary hint level when stuck.
7. State an invariant or proof idea before coding.
8. Test normal, boundary, duplicate, empty, negative, and adversarial cases where applicable.

## Hint Ladder

| Level | Coach action |
| --- | --- |
| 0 | Ask for a restatement |
| 1 | Force constraint and input-property analysis |
| 2 | Elicit brute force and complexity |
| 3 | Isolate the bottleneck |
| 4 | Give one structural observation |
| 5 | Point to a technique family |
| 6 | Name the algorithm and require derivation |
| 7 | Provide pseudocode skeleton only |
| 8 | Help with the exact implementation blockage |
| Full | Only after an attempt and explicit request, or exhausting the ladder |
