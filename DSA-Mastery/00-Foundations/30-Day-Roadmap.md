# 30-Day Roadmap

This is an adaptive NeetCode 150 schedule, not a quota. For this month, FAANG SDE-2 interview performance wins over broad contest coverage. A topic advances only when recall, reconstruction, and transfer produce evidence.

| Days | Focus | Training outcome |
| --- | --- | --- |
| 1-2 | Baseline audit, arrays, hashing | Establish reasoning protocol; identify red/yellow revision pool |
| 3-4 | Two pointers and sliding windows | Derive window invariants from repeated range work |
| 5 | Stack and monotonic reasoning | Connect nearest-element queries to maintained ordering |
| 6 | Binary search | Distinguish ordered search from monotonic-predicate search |
| 7 | Linked lists, mixed recall, Week 1 test | Manipulate pointers safely and classify mixed basics |
| 8-9 | Trees: DFS, BFS, BST | Choose traversal from information flow and build recursive contracts |
| 10-11 | Graph traversal and union find | Model state and connectivity explicitly |
| 12 | Topological sort and shortest-path fundamentals | Recognize dependencies and relaxation conditions |
| 13 | Heap and streaming/top-K | Select structures from required operations |
| 14 | Mixed tree/graph/heap mock | Retrieve without topic labels; diagnose weak areas |
| 15 | Recursion and backtracking | Define choices, state, base cases, and pruning |
| 16-17 | 1D DP and state invention | Derive recurrence from a recursive question |
| 18-19 | 2D, grid, and subsequence DP | Identify dimensions of state and transition order |
| 20 | Knapsack and state-machine DP | Separate capacity/state dimensions from item order |
| 21 | Greedy and intervals | Prove choices with exchange or staying-ahead arguments |
| 22 | DP/greedy contrast drills | Reject tempting but invalid paradigms |
| 23 | Week 3 mock and targeted repair | Explain and code one medium under interview conditions |
| 24 | Tries, bit manipulation, interview-oriented design choices | Expand core toolkit without diluting fundamentals |
| 25 | Pattern combinations and hard-problem workflow | Simplify, constrain, reformulate, then combine interview-relevant techniques |
| 26 | Blind mixed set | Classify before solving, with no pattern labels |
| 27 | Timed contest simulation | Triage, solve order, abandon/re-enter decisions, postmortem |
| 28 | Mock FAANG interview | Communicate, derive, code, test, and defend one unfamiliar medium |
| 29 | Weak-area remediation and spaced reconstruction | Repeat only evidence-backed weak concepts |
| 30 | Final blind assessment and next 8-week plan | Measure demonstrated growth; do not claim readiness from count |

## Daily Session Shape

| Phase | Default time | Output |
| --- | ---: | --- |
| Recall | 15 min | Answer first; then inspect notes |
| New pattern | 25 min | Recognition signals, derivation, invariant, failure conditions |
| Guided problem | 35 min | Attempt log and hint level |
| Blind problem | 35 min | Classification and solution reasoning |
| Transfer / contrast | 25 min | New surface, same pattern or deceptive alternative |
| Interview / reflection | 15 min | Explanation, tests, one failure lesson |

Adjust the duration to available time, but retain recall, a first-principles attempt, and reflection.

## What Is Deferred Until After Day 30

Segment trees, Fenwick trees, SCCs, KMP, rolling hash, computational geometry, and deep contest-specific techniques remain catalogued but are not primary study targets. They enter the next phase after the final assessment identifies a stable core.

## Spaced Repetition Rules

For every important problem schedule: same-day recall, next-day reconstruction, then a transfer or contrast at 3, 7, and 14 days. A failed recall returns to the nearest appropriate level; it does not become a new solved count.
